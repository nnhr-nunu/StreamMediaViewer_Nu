# StreamMediaViewer(ぬ) 製品概要

動きの正本は [spec.md](./spec.md)（2026-09-13 合意）。このファイルは短い案内。

## 何をするか

YouTube の一人配信で、旅行などの写真・動画を紹介する。顔は原則すべてぼかし、操作画面で見てから送ったものだけ OBS に出す。配信用の窓は 1920×1080。何も出していないときと緊急時は窓を隠し、OBS の下のレイヤーを見せる。

## いま動くもの

フォルダの写真・動画を確認し、顔をぼかして、送ったものだけ配信用の窓に出す。未送信・緊急は窓を隠す。手動の四角／手動ぼかし、動画の区間と下準備、星と絞り込み、日英切替、Windows / Mac の zip 配布まで入っている。
