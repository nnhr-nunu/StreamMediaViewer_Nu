# StreamMediaViewer(ぬ) 製品概要

細かい仕様はこれから詰める。ここは現時点の概要であり、変更してよい。

## 目的

配信者が旅行・オフ会などの写真・動画を紹介するとき、顔や個人情報の露出事故を防ぎつつ、手元で快適にメディアを送りたい。

コア価値は次の 3 点。

1. AI と目視の二重チェック
2. 処理完了まで配信側に素顔を出さない
3. テンキー／片手で回せるメディア操作

## 画面分離

- **手元操作 UI**: サムネイル、プレビュー、手動ぼかし、ショートカット
- **配信出力**: 仮想カメラまたは OBS のウィンドウキャプチャ。未送信・処理中・パニックは黒（または指定画像）

## いま実装済み（環境骨格）

- 2 窓起動
- `OutputGate`（起動マスク、送信必須、パニック）
- 設定 JSON の読み書き
- 開発ルール（oshilog 準拠をデスクトップ向けに移植）

## まだないもの

顔検出、フォルダ一覧、手動ぼかし、動画再生、exe 化。`task.md` の Phase 1 以降。
