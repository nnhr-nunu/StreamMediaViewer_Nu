# StreamMediaViewer(ぬ) 仕様（2026-09-13）

YouTube で一人配信する人向け。旅行などの写真・動画を、顔事故なく、片手で送る。細かい文言や見た目は実装時に磨いてよい。ここに書いた動きを勝手に変えない。

言語は日本語と英語を、操作画面右下の **あ/A** で切り替える（最初は日本語）。画面は **アイコンで意味が分かること優先**。文字は短い補助。同じ並びのアイコンを、言語が変わっても動かさない。

## 1. 目的と範囲

やることは、フォルダの写真・動画を確認し、ぼかして、送ったものだけ OBS に出すこと。

やらないこと（他ソフト）: コメント、通知、音のミキサー、OBS のシーン切替。

成功の条件:

- 速さも要るが、処理が終わる前の素顔は 1 コマも配信に出ない
- 写っている顔は自分も含め、原則すべてぼかす（設定でオフ可）
- 操作は配信者ひとり、片手（テンキーと文字キーの両方、マウスでも同じことができる）

## 2. 画面

| 画面 | 役割 |
| ---- | ---- |
| 操作画面 | 一覧、確認、ぼかし、区間、送信、緊急。撮影日時・場所名・ファイル名を出してよい。座標の数字は出さない |
| 配信用の窓 | OBS が取り込む。大きさは 1920×1080。余白は黒。ファイル名も状態の文字も出さない |

配信用の窓は動かせる（2 枚目のディスプレイ想定）。位置は次の起動でも戻す。操作画面は位置と大きさを覚える。

### 2.1 配信用の窓を出す／隠す

OBS の下のレイヤー（ゲームやカメラ）を見せたいときは、**このソフトの絵を出さない**。確実なやり方は、何も出していないときに **配信用の窓を隠す**。見た目だけの透明にはしない（取り込みが不安定になりやすい）。

| とき | 配信用の窓 |
| ---- | ---------- |
| まだ一度も送っていない | 隠す（待機画像を使っているときだけ出して、その画像） |
| 送った写真／動画を出している | 出す（1920×1080） |
| 次のファイルを操作画面で見ている／再生している | **前に送ったもののまま出す**（新しいものは送るまで出ない） |
| 緊急（0 または Esc） | 隠す。待機画像も出さない。もう一度「送る」まで出さない（送るボタンは押せる） |
| ソフトを閉じた | 消える |

待機画像は任意。休憩用。緊急とは別。設定画面で選ぶ。

処理が終わる前は送れない（または押しても配信用は前のまま）。素のコマは出さない。

OBS が「窓が消えたあとも最後の絵を保持する」環境がありうる。そのときは README に、取り込みの設定やソースの再読み込みを短く書く。実装後に実機で確認する。

## 3. ぼかしと安全

- 元の写真・動画ファイルは **書き換えない**。ぼかし・区間・星はソフト側の記録だけ。配信に出す絵はその場で作る。
- 配信に出す絵からは、場所などの埋め込み情報を捨てる。
- 顔の自動ぼかしは最初オン。強さの初期は約 150（最大約 300）。設定でオフ可。オフにしたあと、**最初に送る 1 回だけ**「ぼかしなしで出します」と確認。そのあとはオフのままなら確認しない。オンに戻して再オフしたら、また最初の 1 回確認する。
- 顔の自動ぼかしは楕円（顔の輪郭に近い形）。横顔は正面検出に加えて横向き検出も足す。番号・名札と手動のドラッグ指定は矩形のまま。
- 見た目の自動補正は、ぼかしのあとにかける。手元の確認と送ったあとの配信の両方。✨ を押すたびに オフ → 弱 → 強。最初は弱（コントラスト 1.12・彩度 1.15）。強はそれよりはっきり上げる。元ファイルは書き換えない。待機画像にはかけない。
- 自動が見逃しても送れる。「手動ぼかし」（💧）をオンにすると、その右にドラッグ指定・筆・戻す・クリアが枠付きで出る。初期はドラッグ指定。筆のときだけ、筆の隣に太さが出る。確認画面は元の絵の形のまま（配信用の黒帯は付けない）ので、塗った場所とぼかしがずれることはない。Ctrl+Z と戻すで直前を取り消す（最大 10 回）。自動の顔ぼかしはこれでは消えない。
- 車の番号・名札の自動も最初の版に入れる。**最初の値はオフ**。外れうる。オンのときだけ一覧に印を出す。
- 手動ぼかしはファイルに紐づけて残す（ソフトを閉じても残る）。

## 4. フォルダ・一覧

- 配信のたびにフォルダを 1 つ指定する。最近使ったフォルダからも開ける。
- **下の階層のフォルダも読む**。最初はオン。設定でオフにできる。操作画面の絞り込みで、下のフォルダだけに絞れる。
- 対応: よくある写真（JPEG / PNG / WebP / BMP）、iPhone の HEIC、よくある動画（MP4 / MOV / MKV / WebM / AVI）。読めないものは一覧で飛ばし、操作画面にだけ「開けません」。
- 並びは同じ行の右端「ソート」で変える。最初は撮影日時の古い順。新しい順／名前順も選べる。日時が無いものは後ろ（名前順のときは名前だけ）。ランダム並びは作らない。
- 星は確認プレビューの右上（☆ → ⭐）。絞り込みは枠と見出しでまとめる。項目: 星（⭐）／写真／動画／開始日〜終了日／おおまかな場所名／下のフォルダ。場所の一覧に「位置情報なし」を入れる。顔ありの絞り込みは出さない。日付のチェックは日付の欄のすぐ左。日付はカレンダーで選ぶ。フォルダ・場所・日付の欄は 🔽 でプルダウンだと分かるようにする。日付の幅はフォルダ内で取れた最古〜最新に合わせる（絞り込み自体はオフのまま）。
- 印: 顔がありそうなら「顔あり」。⚠ は使わない。番号・名札は、その自動がオンのときだけ。事前処理できたものは ✓、いま視聴者に出しているものは 【表示中】。動画の縮小画には再生の印を付ける。日付と場所は 1 行にまとめる。
- 操作画面の一覧には大きな縮小画を出す。幅が足りなければ 1 行 1 枚。十分な幅があれば 1 行 2 枚にし、さらに余白があればその 2 枚を大きくする。ファイル名は一覧に出さず、確認欄の上とカーソル説明に出す。配信用の窓には出さない。
- フォルダを開く処理は裏で進める。件数が多いときも操作画面は止めない。「読み込み中」の下に件数と進捗バーを出す。進捗は中央に置く。
- 「確認用の画像を作成中…」は処理中だけ。終わったら撮影日時・場所名・ファイル名などに戻す。
- 一覧のクリック・タップは **確認だけ**。配信は「送る」まで変わらない。
- 写真を選んでいるときは再生・区間・繰り返し・このファイルの下準備を出さない。動画のときだけ出す。
- 前・次・送る・隠すなど写真でも使うボタンの位置は動かさない。動画専用（再生・このファイルの下準備）は右端に出す。

操作画面に出す情報: 撮影日時、場所名（GPS があるときはおおまかな街名。座標の数字は出さない）、ファイル名、下のフォルダ、動画のときは「動画」と長さ、顔あり。写真であることは書かない。配信用の窓には出さない。

最初にフォルダを選ぶ前は、「フォルダを選択して下さい」と短い手順を操作画面に出す。配信用の窓には出さない。

## 5. 動画

- 再生しながら 1 コマずつ顔を処理し、終わったコマだけ配信用の窓に出す。
- 選んだ区間は裏で事前処理できる（⏳。選んだときも自動で始める）。「ぼかしの事前処理」で今のフォルダもできる。目安の容量を出してから始める。「事前処理データを削除」は処理結果だけ消す。フォルダ内の写真・動画は消さない。星・区間・手動ぼかしは残す。確認で「このフォルダの下準備」か「下準備を全部」を選ぶ。一覧は 【表示中】＝いま出している、✓＝事前処理できた。
- 動画の区間棒は「始まり」「終わり」と書き、色を分ける。写真では出さない。
- 準備が間に合わないときは、生の顔を出さず **再生を遅らせる**。検出を飛ばして素のコマを出す、はしない。
- 音は配信者の設定。**最初はオフ**。**送ったあとだけ**出す（確認中の再生では出さない）。OBS のデスクトップ音声に乗る。
- 送る前の再生は配信に乗らない。
- 送ったら、決めた区間の先頭から自動再生。区間はドラッグで決め、ファイルに残す。
- 区間の終わりは最後のコマで止める。その動画に「繰り返す」が付いていれば区間を繰り返す。繰り返しは **動画ごと**。最初はオフ。全体の一括スイッチは作らない。
- もう一度見るときは Space または再生ボタン（マウス可）で、区間の先頭から。区間の外は再生しない。
- 再生／停止は **動画を選んでいるときだけ**。Space、テンキー 5、画面上のボタン。写真では再生ボタンを出さない。今の動画の下準備は ⏳。フォルダ全部は「ぼかしの事前処理」。事前処理データを削除（元ファイルは消さない）。

## 6. キー（両方同じ意味）

| 操作 | テンキー | 文字キー | マウス |
| ---- | -------- | -------- | ------ |
| 前 | 4 | A | ボタン／一覧 |
| 次 | 6 | D | ボタン／一覧 |
| 送る | Enter | Enter | 送るボタン（アイコン優先） |
| 緊急で窓を隠す | 0 | Esc | 緊急ボタン |
| 再生／停止 | 5 | Space | 再生ボタン／動画の画面をクリック |
| 星 | 同じ位置のアイコンでも可 | F | 確認プレビュー右上の☆ |
| やり直し | | Ctrl+Z | 戻すアイコン |
| キー一覧 | | | 右下の ？（キー説明）。左隣があ/A |

キーの割り当て変更は、最初の版では必須にしない（今の対応表で固定）。

## 7. 保存

閉じるときに自動保存: 設定、星、再生区間、繰り返し、手動ぼかしと太さ、一覧の並び、顔ぼかしオンオフ、番号・名札自動、音、色の自動補正、言語、下のフォルダも読むか、待機画像の有無とパス、操作画面の位置と大きさ、配信用の窓の位置。毎回「保存する？」は出さない。

開発中の設定ファイルの場所は README の通り。写真フォルダの中には書き込まない（原本を汚さない）。

## 8. 見た目

- 暗い画面。配信中に光らない。
- 主な操作は大きく、片手でも当たる。
- アイコンだけでは分かりにくいボタンには、短い説明を添える。
- 版の番号は ⚙ の設定に置く。言語は右下の あ/A。設定には、画面上に既にあるぼかしオンオフや自動補正を重ねて出さない。
- 配信用の窓には装飾も文字も出さない。
