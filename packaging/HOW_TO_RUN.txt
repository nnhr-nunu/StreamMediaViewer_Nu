StreamMediaViewer(ぬ)

起動するもの:
- Windows: StreamMediaViewer.exe
- Mac: StreamMediaViewer.app

1. この ZIP を展開する
2. 上の「起動するもの」を開く（インストール不要）
3. 📁 で写真フォルダを開く → 確認 → ⬆ で送る
4. OBS「ウィンドウキャプチャ」で次の名前を選ぶ
   StreamMediaViewer(ぬ) - 配信出力

送るまで／緊急（Esc またはテンキー 0）では窓が消えます。
動画は ⏳ で先に準備すると、配信中に遅れにくくなります。

Windows: StreamMediaViewer-windows.zip の StreamMediaViewer.exe
Mac（Apple チップ）: StreamMediaViewer-macOS.zip の StreamMediaViewer.app
Mac（Intel）: StreamMediaViewer-macOS-intel.zip の StreamMediaViewer.app

OBS で古い絵が残るときは、キャプチャ方法を「Windows 10 (1903 以降)」にし、
「ウィンドウが無いときは何も表示しない」があればオンにしてください。

詳しくは GitHub の README を見てください。
